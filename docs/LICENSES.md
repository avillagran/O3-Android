# Third-party material shipped in the APK

Each entry: what ships, where, its licence and how it was obtained. The full licence texts
ship in the APK under `app/src/main/assets/licenses/` for the Licenses page (UI_SPEC 4.9).

## Fira Code 6.2

- Files: `app/src/main/res/font/fira_code_regular.ttf`, `fira_code_medium.ttf` (the
  release's `ttf/FiraCode-Regular.ttf` and `ttf/FiraCode-Medium.ttf`, unmodified).
- Licence: SIL Open Font License 1.1, copyright 2014 The Fira Code Project Authors;
  text in `app/src/main/assets/licenses/fira-code-OFL.txt` (the repository's `LICENSE`
  at tag `6.2`).
- Source: <https://github.com/tonsky/FiraCode/releases/download/6.2/Fira_Code_v6.2.zip>,
  downloaded 2026-10-25. GitHub publishes no digest for this asset; its SHA-256
  `0949915ba8eb24d89fd93d10a7ff623f42830d7c5ffc3ecbf960e4ecad3e3e79` matches the one
  Homebrew's `font-fira-code` cask pins for the same URL.
- SHA-256 of the bundled files: Regular
  `5992ab9640e2df491b2f609467b1de60e8bc39b2c28db184342a0592d98f6117`, Medium
  `97091f90623661fb4f7979c10d188f30f4806d8ce326b0bc8d1acc79dcc20d8f`.
